# 🔔 @ling-recalled 範例指令

回報「我記得這條！」——複習完 `@ling-quiz` 的卡片後，用這個指令告訴 Ling-Ling 你成功回想起某條主張，
系統就會**強化**那條記憶：拉長它的半衰期，下次更晚才需要複習。這是複習迴圈的收尾動作。

> [!TIP]
> **發動方式**：在 `toLingLing/` 建一個檔案，用 `[[主張全文]]` 指定你記得的那條。
> **原理**：成功的主動回想會觸發一次 `GAIN_RETRIEVAL` 強化——記憶強度 S 上升、可提取度 R 重設，於是下次的複習被自動排到更遠的未來（間隔重複的核心）。

---

## 範例 1：回報記得某條主張（從複習卡複製主張全文）
```markdown
@ling-recalled [[複雜度管理的本質在於放棄對過程細節的微觀控制，轉而擁抱更具通用性的工具與抽象。]]
```

## 範例 2：一次回報多條
```markdown
@ling-recalled [[熵總是增加]] [[重力會使時間變慢]]
```

## 範例 3：斜線寫法
```markdown
/recalled [[分析品質受到輸入資料完整性與分析粒度收斂程度的嚴格制約。]]
```

---

### 輸出長什麼樣
- 一句確認：強化了哪幾條、各自的 S 上升了多少。
- 找不到對應主張時會誠實說「找不到」，不會亂記。

### 小提醒
- `[[...]]` 裡放**複習卡上的主張全文**最準；系統也會用檔名或子字串盡量對應。
- 只在你**真的**回想起來時才回報——虛報會讓系統以為你記得，反而提早停止提醒你。
- 忘記了就不要回報，讓它下次再考你一次（那正是它該做的）。
