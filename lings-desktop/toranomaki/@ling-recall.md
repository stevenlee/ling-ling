# 🧠 @ling-recall 範例指令

回想——給一個主題，Ling-Ling 從 **Cortex 長期記憶**（蒸餾過的信念）撈出最相關的主張，
連同信心、可反駁性、反例、證據鏈與矛盾一起呈現。

> [!TIP]
> **發動方式**：在 `toLingLing/` 建一個檔案，內容用下面任一格式。報告寫入 `fromLingLing/`。
> **與 `@ling` 問答的差別**：`@ling` 從**原始筆記**檢索回答；`@ling-recall` 從系統**蒸餾過的信念**回答（「我目前相信什麼」），並主動攤開不確定性。

---

## 範例 1：問一個具體主題
```markdown
@ling-recall 關於 Hilbert，我記得什麼？
```

## 範例 2：問一個概念（用你自己的話即可）
```markdown
@ling-recall AI agent 協作系統要怎麼對抗任務分解的熵增？
```

## 範例 3：口語、甚至拼錯字也沒關係
```markdown
@ling-recall 我之前對蒙地卡羅怎麼選種子有什麼想法
```
> recall 由 LLM 讀過全部信念後對應，能容錯（例如把 `Hibert` 對應到 `Hilbert`、把不同說法對應到同一主張），不需要精確關鍵字。

## 範例 4：斜線寫法
```markdown
/recall 複雜度管理
```

---

### 輸出長什麼樣
- 一段繁體中文綜述「關於這個主題，系統相信什麼」，每個論點標 `[#編號]` 溯源。
- **主動點出不確定性與矛盾**（自我批判的鏡子，不是附和）。
- 附錄列出被引用的主張，含 **信心 / 可反駁性 / 反例 / 證據 wikilink**。
- 若 Cortex 裡沒有相關的，會直接說「沒有相關的信念」，不硬湊。

### 小提醒
- Cortex 越大、主張越具體，recall 越有鑑別度；剛起步、語料還少時結果會比較發散。
- 想看「信念之間的衝突 / 教條 / 證據單薄」而不是「相信什麼」，改用 `@ling-tensions`。
