# 📓 @ling-consolidate 範例指令

立刻把**未鞏固的 insight** 蒸餾成原子主張、併進 `Cortex/`（hippocampus→neocortex）。
平常由夜間排程與白天的白日夢慢慢消化；這個命令是「現在就清積壓」。

> [!TIP]
> **發動方式**：在 `toLingLing/` 建一個檔案。摘要寫入 `fromLingLing/`，新主張進 `Cortex/`。

---

## 範例：消化積壓
```markdown
@ling-consolidate
```

## 斜線寫法
```markdown
/consolidate
```

### 小提醒
- 與夜間鞏固共用 `processed` 狀態，**不會重複處理**同一條 insight。
- 想看蒸餾後的信念，用 `@ling-recall`；想看信念的矛盾，用 `@ling-tensions`。
