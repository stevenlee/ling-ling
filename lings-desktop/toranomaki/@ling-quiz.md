# 🎴 @ling-quiz 範例指令

複習卡——Ling-Ling 從 **Cortex 長期記憶**挑出你**快要忘記**的主張，出成一張「主動回想」卡：
先給提示、把答案藏起來，讓你自己先想再翻牌。這是間隔重複（spaced repetition）的學習輔助。

> [!TIP]
> **發動方式**：在 `toLingLing/` 建一個檔案，內容如下。複習卡寫入 `fromLingLing/`。
> **原理**：系統本來就在幫每條信念算「可提取度 R」（會隨時間衰減）。R 剛滑到「快忘、但還救得回」的甜蜜點時，正是複習 CP 值最高的時刻——這張卡就挑那些主張。
> **自動版**：每天排程也會自動出一張，不必手動要。這個指令是「我現在就要一張」。

---

## 範例 1：要一張複習卡
```markdown
@ling-quiz
```

## 範例 2：斜線寫法
```markdown
/quiz
```

---

### 輸出長什麼樣
- 幾則「提示 → 翻牌看答案」的卡片：提示描述**適用情境**（不直接說出主張），答案摺在 `<details>` 裡。
- 每張卡附目前的熟悉度 `R`，以及一句「記得的話投 `@ling-recalled [[主張]]`」。
- 若今天沒有快忘的，會挑幾條**最久沒碰**的當「不急的溫習」，並標明不緊急——不會給你空卡。
- 若 Cortex 還沒有可複習的主張，會直接說明。

### 小提醒
- 複習後記得用 `@ling-recalled` 回報，系統才會把那條記得更牢、下次更晚才問你（見 `@ling-recalled`）。
- 想看「我相信什麼」用 `@ling-recall`；想看「信念哪裡有問題」用 `@ling-tensions`；這裡是「幫我記住」。
