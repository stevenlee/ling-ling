# 💬 @ling-tensions 範例指令

知識張力掃描——`@ling-recall` 的反面。recall 答「我相信什麼」，tensions 答
「我的信念在哪裡**有問題**」。對抗自我印證、避免知識同溫層用。

> [!TIP]
> **發動方式**：把這個檔案直接拖進 `toLingLing/`（不需要參數，它會掃整個 Cortex）。
> 報告寫入 `fromLingLing/`。純掃描、不呼叫 LLM，所以很快、也不受檢索品質影響。

---

## 最簡單：拖檔即可
```markdown
@ling-tensions
```
或斜線寫法：
```markdown
/tensions
```

---

### 報告會攤開四種張力
1. **💬 矛盾對**：知識庫裡互相打架的主張（A↔B，已去重、解析成主張全文）——活的異議。
2. **🧱 教條風險**：**高信心、低可反駁性**的主張。寫不出反例＝無法被推翻＝只會自我強化，
   是同溫層的結構性燃料。優先重新檢視，或替它補上可檢驗的反例。
3. **🪶 證據單薄**：只靠 ≤1 個來源支撐的主張。
4. **🍂 已被推翻**：status 為 falsified 的主張（透明保留，附死因）。

### 建議時機
- 跑了幾晚 dreaming window、Cortex 長出一批主張之後，想體檢「我的信念健不健康」。
- 看到 `@ling-recall` 或 `@ling-cortex` 報告裡可反駁性偏低時，用這個把教條主張集中揪出來。
- 把「覺得該重想」的主張，回去原始筆記補證據或直接刪頁——刪除就是品質投票。

### 微調（一般不用動，可在環境變數設定）
- `CORTEX_TENSION_DOGMATIC_FALS`（預設 0.25）：可反駁性低於此且信心夠高 → 列為教條。
- `CORTEX_TENSION_DOGMATIC_CONF`（預設 0.5）：教條判定的信心門檻。
- `CORTEX_TENSION_THIN_EVIDENCE_MAX`（預設 1）：來源數 ≤ 此值 → 列為證據單薄。
